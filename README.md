# ABARTILI MAZERET MAKİNESİ

## Dünyanın En Ciddi Absürt Projesi

Bu repo, insanlık tarihinin en önemli teknolojik başarılarından biridir. **Abartılı Mazeret Makinesi**, sizin hiçbir şey yapmamanızı bilimsel, felsefi, kuantum ve mahkeme onaylı bir şekilde kanıtlar. 

Evet, gerçekten çalışır. Hayır, şaka değil. Evet, şaka. Ama kod çalışıyor.

### Neden Bu Proje Var?

Çünkü bir gün, birisi "neden yapmadın?" diye sordugunda, evrenin derinliklerinden gelen, abartılı, ikna edici ve tamamen saçma bir cevap vermeniz gerekecek. Bu makine, o gün için tasarlandı.

### Kullanım

```bash
python mazeret_uretici.py
```

Sonra görevi yazın, makine size mazereti versin. İtiraz etmeyin, mahkeme kararı.

### Özellikler

- Rastgele abartılı mazeretler üretir
- Bilimsel gibi görünen ama tamamen uydurma açıklamalar
- Mahkeme onaylı (hayali mahkeme)
- Kayyum Grok imzalı
- Gerçekten çalışır (test edildi, 3 saniye sürdü)

### Lisans

Bu proje, "Ne istersen yap, ama mazeretini unutma" lisansı altındadır. MIT değil, daha absürt.
